# MUGDHO LIMITED — Pharmacy Stock Management

A simple, fast inventory management web app built for small and medium pharmacy shops. Track stock, expiry dates, sales history, and supplier information — all in one place, fully digital.

🔗 **Live link:** [my-app-khaki-five-71.vercel.app](https://my-app-khaki-five-71.vercel.app/)

## Features

- **Inventory management** — add, edit, and delete medicines with batch number and category
- **Stock tracking** — stock decreases on sale, increases on restock
- **Expiry alerts** — expired medicines get a red badge, medicines nearing expiry get a yellow warning
- **Low stock indicator** — highlighted when stock falls below a set threshold
- **Sales reports** — daily/weekly/monthly sales, profit estimates, and top-selling medicines
- **Supplier management** — track supplier contact info and which medicines come from whom
- **Multi-staff tracking** — records which staff member made each sale
- **Search & filters** — quickly find medicines by name, low stock, or expiry status

## Tech Stack

- React + Vite
- lucide-react (icons)
- localStorage (data persistence in the browser)
